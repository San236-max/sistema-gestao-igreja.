# Sistema de Gestão da Igreja

## Sobre o projeto

O Sistema de Gestão da Igreja é um projeto desenvolvido para auxiliar na organização dos eventos e das tarefas administrativas da Igreja Adventista do Sétimo Dia de Geniparana.

O objetivo é facilitar o acesso às informações, melhorar a comunicação e centralizar os registros importantes.

## Funcionalidades

- Cadastro de eventos.
- Consulta de eventos.
- Cadastro de tarefas.
- Acompanhamento das tarefas.
- Armazenamento de informações em banco de dados.

## Tecnologias utilizadas

- Python
- SQLite

## Estrutura do projeto

- main.py: arquivo principal do sistema.
- database.py: conexão e criação do banco de dados.
- eventos.py: gerenciamento de eventos.
- tarefas.py: gerenciamento de tarefas.
- README.md: documentação do projeto.

## Banco de dados

O projeto utiliza SQLite para armazenar os eventos e as tarefas de maneira organizada.

## Objetivo

Desenvolver uma solução simples e acessível para melhorar a organização das atividades da igreja.
